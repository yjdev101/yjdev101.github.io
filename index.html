유효한 토큰에 403이 반환되던 문제

JwtAuthenticationFilterSecurityConfig인증 · 에러 처리

문제
유효한 토큰으로 요청해도 403이 반환되었습니다. 서버 로그 확인 결과 인증은 정상 통과했으며, 실제로는 컨트롤러에서 예외가 발생한 상태였습니다.
원인
예외 발생 시 Spring은 요청을 /error로 재전달합니다. 그러나 JWT 필터(OncePerRequestFilter)는 에러 디스패치를 다시 처리하지 않아 /error가 미인증 요청으로 차단되었고, 본래 500이어야 할 응답이 403으로 가려졌습니다.
해결
/error를 permitAll에 추가해 실제 오류가 드러나도록 했습니다. 이후 전역 예외 처리를 도입해 예외 유형별로 404·400·401을 구분해 응답하도록 개선했습니다.

commit 8074c4fFileStorageServiceMultipartFile.transferTo파일 업로드

문제
영상 업로드 시 FileNotFoundException이 발생했습니다. 오류에 표시된 경로는 프로젝트 디렉터리가 아닌 톰캣 임시 디렉터리 하위였습니다.
원인
동일한 상대경로를 두 API가 서로 다른 기준으로 해석했습니다. 디렉터리를 생성한 Files.createDirectories는 애플리케이션 실행 위치를, 파일을 저장한 transferTo는 톰캣 임시 디렉터리를 기준으로 삼았습니다.
해결
절대경로로 변환해 전달하도록 수정했습니다. 아울러 파일명을 UUID로 대체하고 확장자를 허용 목록으로 제한해 파일명 충돌과 경로 조작(Path Traversal)을 방지했습니다.
